# Market Regime & Machine Learning Prediction

**市场状态与机器学习方向预测能力**

一个样本外、无未来信息泄漏的实证项目：检验同一批机器学习模型在高波动与低波动市场状态下的方向预测能力是否存在显著差异。

---

## 1. 项目背景：从「能不能直接用 K 线预测涨跌」开始

项目最初出发于一个很直接的好奇心：**能否只用 K 线数据预测股票走向？**

具体设想是：取每只股票的每日开盘价与收盘价，构造"当天收盘相对开盘涨跌"这一方向标签，再配上少量由 K 线（OHLCV）派生的技术特征，直接用三个代表性的分类模型——**逻辑回归（Logistic Regression）、随机森林（Random Forest）、XGBoost**——去预测方向，并以**分类准确率（Accuracy）作为主要评价指标**。核心期待是：既然价格形态里存在动量、反转、波动聚集等现象，模型理应能在方向上有一定胜率。

**实际结果证明：不能。** 在严格样本外的设定下，三个模型的准确率全部回归到 0.5 附近的抛硬币水平，相对多数类基线的优势在统计上不显著，且这一负结果在更换市场状态定义、更换标的、更换训练窗口后依然稳健。

项目因此从"追求更高的预测准确率"转向了一个更可检验的问题：**在无法战胜基线的前提下，预测能力是否会随市场状态（高/低波动）系统性变化？** 答案同样是否定的——但这一结论本身是稳健且可复现的，构成了本项目的主要产出。

## 2. 结论速览

| 模型 | All BA | Low Vol BA | High Vol BA | Delta_BA |
|---|--:|--:|--:|--:|
| LogisticRegression | 0.497 | 0.500 | 0.488 | −0.011 |
| RandomForest | 0.501 | 0.501 | 0.504 | +0.004 |
| XGBoost | 0.505 | 0.506 | 0.501 | −0.003 |
| 多数类基线 | 0.500 | 0.500 | 0.500 | 0.000 |

- 所有模型的 BA / AUC 均在 0.5 附近，**没有任何一个 Delta_BA 在 95% 置信区间下显著**（Bootstrap CI 全部跨 0）。
- 高波动组样本占比约 28.8%，标签正例率约 53.8%，接近抛硬币。
- 上述数字可由 `outputs/spy_results.csv` 直接复算得到。

## 3. 研究问题

> 同一个机器学习模型，在高波动与低波动市场状态下的样本外方向预测能力是否存在显著差异？不同学习范式（线性 / Bagging / Boosting）之间的差异幅度是否不同？

核心度量指标为 `Delta_BA = BA(高波动) − BA(低波动)`，以移动区块 Bootstrap 的 95% 置信区间判断显著性。

**定位说明**：项目的目标不是"找出最准的模型"，而是用一套严格（样本外、无泄漏、多范式、含 Bootstrap CI、含多组稳健性检验）的框架，实证回答"方向预测能力是否随市场状态变化"。

## 5. 方法

### 5.1 预测标签

```
y(t) = 1  若 Close(t+1) > Open(t+1)   （次日开盘→收盘为涨）
y(t) = 0  否则
```

即**只用信息到第 t 日为止，预测第 t+1 日的日内方向**。该标签剥离了隔夜跳空信息，是金融文献中信噪比最低的预测目标之一——这也是后续负结果的根本原因之一。

### 5.2 特征（8 个，全部由 t 日及以前的数据构造）

| 类别 | 特征 |
|---|---|
| 收益 | `ret_1d`、`ret_5d`、`ret_20d`（对数收益的 1/5/20 日累计） |
| 趋势 | `dist_ma5`、`dist_ma20`（收盘价相对 5/20 日均线的偏离） |
| 波动 | `rv_5d`、`rv_20d`（5/20 日已实现波动率，年化） |
| 量能 | `vol_zscore_20d`（成交量相对 20 日均值的 Z-score） |

8 个特征均为同一份 OHLCV 的简单变换，信息高度重叠，不含任何外生信号（宏观、跨资产、资金流等）。

### 5.3 市场状态划分

- 以 `rv_20d` 为状态变量，阈值取**训练集**（而非全样本）的 **70 分位数**，避免使用未来信息。
- 当日 `rv_20d` 高于阈值 → 高波动（regime = 1），否则低波动（regime = 0）。

### 5.4 模型与超参数搜索

| 范式 | 模型 | 搜索网格 |
|---|---|---|
| 线性 | LogisticRegression | `C ∈ {0.01, 0.1, 1, 10}`（配 StandardScaler） |
| Bagging | RandomForestClassifier | `n_estimators ∈ {100, 300}`，`max_depth ∈ {3, 5, 10}`，`min_samples_leaf ∈ {5, 10}` |
| Boosting | XGBClassifier | `n_estimators ∈ {100, 300}`，`max_depth ∈ {3, 5}`，`learning_rate ∈ {0.01, 0.1}`，`subsample = 0.8` |

- 使用**小型固定网格 + `TimeSeriesSplit(3)` 时序交叉验证**手工搜索，不使用 `RandomizedSearchCV` 等会打乱时序的搜索方式。
- 另设"训练集多数类"作为简单基线。
- 随机种子固定：`RANDOM_STATE = 42`。

### 5.5 训练与测试协议

- **初始训练期**：2005-01-01 ~ 2014-12-31。
- **样本外测试期**：2015-01-01 ~ 2025-12-31，共 44 个测试季度。
- **季度扩张窗口**（expanding window）滚动重拟合；**每年首个季度**重新做一次网格调参，其余季度只重拟合不调参。
- 三个模型**共享完全相同的特征、训练期与测试期**，保证可比。
- 所有设计选择（资产、区间、窗口、指标）在查看任何模型结果**之前**即固定，避免事后挑选。

### 5.6 评价指标

- **主要指标：分类准确率（Accuracy）**。由于需要在高/低波动两个子样本间做可比比较，且两组的类别分布不同，实现上采用 **Balanced Accuracy（平衡准确率，即正负类召回率的平均）**，并据此计算 `Delta_BA`。
- **次要指标：ROC-AUC**。
- **显著性：移动区块 Bootstrap（block size = 20，n_boot = 1000）** 估计 `Delta_BA` 的 95% 置信区间，区间跨 0 即视为不显著。

### 5.7 稳健性检验

| 编号 | 内容 |
|---|---|
| 8.1 | 更换市场状态定义（不同波动率窗口，1a / 1b 两组） |
| 8.2 | QQQ 外部验证，完整复现同一流程 |
| 8.3 | 改为 5 年固定长度滚动窗口训练 |

三组检验结论一致：`Delta_BA` 均极小且不显著，且**符号在不同设定之间来回翻转**。

## 9. 为什么预测不了（负结果的解释）

结论是：**这是一个稳健的负结果，根因在研究对象本身，而不是工作流缺陷。**

1. **预测目标近乎不可预测**：日内 open→close 方向剥离了隔夜信息，是金融数据中信噪比最低的目标之一；标签分布约 54/46，接近抛硬币。
2. **特征无增量信息**：8 个特征都是同一份 OHLCV 的简单变换，彼此高度重叠，不含宏观、跨资产、资金流等外生信号。
3. **模型无法在无信号数据上产生差异**：年度调参在样本外无法泛化，三个模型的 BA 都回归到 0.5 基线，差异被压缩到 ±0.01 量级。
4. **分组样本不平衡削弱统计功效**：高波动组仅占约 29%，Bootstrap 置信区间较宽，更难达到显著。

这一结果呼应了市场中常见的"方向不可预测、但波动率可预测"的不对称现象：同样的价量数据可以较好地刻画波动（`rv_20d` 本身就是状态划分的依据），却几乎无法指示方向。
